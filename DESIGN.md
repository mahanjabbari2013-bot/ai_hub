## Brand & Style

The design system establishes an authoritative, cutting-edge aesthetic tailored for discerning developers, researchers, and enterprise decision-makers evaluating artificial intelligence systems. It delivers an instrument-grade, high-density experience that balances editorial rigor with futuristic precision.

The aesthetic fuses **Precision Glassmorphism** with **Technical Minimalism**:
- **Atmosphere:** Deep cosmic field environments illuminated by controlled photonic linear gradients, laser-sharp boundaries, and selective optical glow effects.
- **Bi-directional Parity:** Native Right-to-Left (Persian/Farsi) architecture treated as first-class, mirroring spatial layouts, icon orientations, badge placements, and typographic proportions seamlessly into Left-to-Right (English).
- **Tone:** Objective, technical, and analytical. Surfaces mimic precision-milled glass instruments and telemetry consoles rather than decorative novelties.

## Colors

The palette employs deep chromatic darks as the default ground, layered with laser-sharp electric accents for telemetry, category identification, and interaction states.

### Core Architecture
- **Canvas Base (Deep Space):** `#0A0F1D` — Deep void baseline for zero-glare computational contrast.
- **Surface Elevation (Navy/Slate):** `#0F172A` — Primary container ground.
- **Interactive Primary (Electric Blue):** `#3B82F6` (Hover: `#2563EB`) — Critical actions, primary filters, active evaluation targets.
- **Accent Cyan (Photonic Teal):** `#06B6D4` — Performance metrics, benchmark ratings, active nodes.
- **Accent Violet (Neural Violet):** `#8B5CF6` (Hover: `#7C3AED`) — Deep learning classifications, composite multi-model indices.
- **Accent Emerald (Signal Green):** `#10B981` — Verified status, operational uptime, superior benchmark score deltas.

### Category Taxonomy Tokens
To ensure instantaneous cognitive scanning across dense model directories:
- **Conversational / LLM:** Background `rgba(59, 130, 246, 0.12)`, Border `rgba(59, 130, 246, 0.35)`, Text `#60A5FA`
- **Vision / Image:** Background `rgba(139, 92, 246, 0.12)`, Border `rgba(139, 92, 246, 0.35)`, Text `#A78BFA`
- **Code & Logic:** Background `rgba(6, 182, 212, 0.12)`, Border `rgba(6, 182, 212, 0.35)`, Text `#22D3EE`
- **Video Generation:** Background `rgba(236, 72, 153, 0.12)`, Border `rgba(236, 72, 153, 0.35)`, Text `#F472B6`
- **Audio / Voice:** Background `rgba(245, 158, 11, 0.12)`, Border `rgba(245, 158, 11, 0.35)`, Text `#FBBF24`
- **Search & Retrieval:** Background `rgba(16, 185, 129, 0.12)`, Border `rgba(16, 185, 129, 0.35)`, Text `#34D399`

### Light Mode Inversion Protocol
When rendered in `light` mode:
- Canvas shifts to `#F8FAFC`, with surface cards at `#FFFFFF` and borders at `#E2E8F0`.
- Text targets contrast ratios $\ge 7:1$ utilizing `#0F172A` for primary headlines and `#475569` for body copy.
- Accent colors deepen by one shade (`#2563EB`, `#0891B2`, `#7C3AED`, `#059669`) to retain luminance legibility against white substrates.

## Typography

The dual-language typography stack pairs **Vazirmatn** (for Persian/Arabic script) with **Inter** (for Latin script and tabular numbers).

### Dual Script Mapping Rules
- **Persian Context (`dir="rtl"`, `lang="fa"`):**
  - Font Family: `Vazirmatn`, system fallback `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto`.
  - Line-height modifiers: Multiply all default Latin line-height values by `1.15x` to prevent clipping of extended Persian ascenders, descenders, and accent marks (Tashkeel).
  - Letter spacing: Always enforce `letter-spacing: 0` for Persian script to preserve cursive ligature continuity.
- **English Context (`dir="ltr"`, `lang="en"`):**
  - Font Family: `Inter`, system fallback `sans-serif`.
  - Apply negative tracking (`-0.025em` to `-0.01em`) across headlines to achieve a condensed, modern technical silhouette.
- **Numerals & Metrics:**
  - In technical comparisons, score metrics, benchmark matrices, and latency figures, always enforce tabular figures (`font-variant-numeric: tabular-nums`) across both Persian and English presentations.

## Layout & Spacing

Layout geometry follows an analytical grid designed for high-density benchmark tables, card matrices, and multi-model diff inspectors.

### Grid & Breakpoints
- **Desktop ($\ge 1280\text{px}$):** 12-column fluid grid, `1280px` or `1440px` max-width container, `gutter: 1.5rem`, `margin: 2rem`. Sidebars for parameter filtering anchor to 280px fixed width while the comparison matrix expands dynamically.
- **Tablet ($768\text{px} - 1279\text{px}$):** 8-column layout, `gutter: 1rem`, `margin: 1.5rem`. Filter panels collapse into an off-canvas drawer.
- **Mobile ($< 768\text{px}$):** 4-column layout, `gutter-sm: 1rem`, `margin-sm: 1rem`. Model comparison charts transition from multi-column grids to swipeable horizontal cards or sticky dual-column diff views.

### Bi-directional Spacing Protocol
- Structural flow relies on logical CSS properties (`margin-inline-start`, `padding-inline-end`, `inset-inline`).
- Under RTL layout, asymmetric gutters and indicator pips switch horizontal alignment automatically without manual class overrides.

## Elevation & Depth

Visual depth is achieved through layered frosted substrates, physical back-drop blurs, and spectral hairline borders rather than traditional diffused drop shadows.

### Surface Tiers
- **Tier 0 (Canvas Void):** `#0A0F1D` (Solid, zero elevation).
- **Tier 1 (Base Container):** `background: rgba(15, 23, 42, 0.65)`, `backdrop-filter: blur(12px)`, border: `1px solid rgba(255, 255, 255, 0.08)`.
- **Tier 2 (Elevated Card / Active Tile):** `background: rgba(15, 23, 42, 0.85)`, `backdrop-filter: blur(16px)`, border: `1px solid rgba(59, 130, 246, 0.25)`.
- **Tier 3 (Overlay / Modal / Flyout Menu):** `background: rgba(15, 23, 42, 0.95)`, `backdrop-filter: blur(24px)`, border: `1px solid rgba(255, 255, 255, 0.15)`.

### Border & Glow Rules
- Never use heavy drop shadows. Instead, apply focused luminescence on active or hovered states:
  - **Primary Element Glow:** `box-shadow: 0 0 24px -4px rgba(59, 130, 246, 0.35)`
  - **Cyan Subsystem Glow:** `box-shadow: 0 0 24px -4px rgba(6, 182, 212, 0.35)`
- All borders must remain crisp hairline dividers (`1px` width) rendered in semi-transparent rgba shades to let underlying neon or dark ambient gradients reflect naturally.

## Shapes

The design uses balanced, modern radii (`roundedness: 2`, where base radius is `0.5rem` / `8px`):
- **Base Components (Inputs, Buttons, Tags):** `rounded-md` (`0.5rem` / `8px`) for tight structural precision.
- **Containers & Model Cards:** `rounded-lg` (`1rem` / `16px`) delivering a sleek frame for complex tabular data.
- **Floating Modals & Comparison Drawers:** `rounded-xl` (`1.5rem` / `24px`) highlighting detached elevation.
- **Status Indicators & Micro-badges:** Full pill styling (`9999px`) to distinguish categorical tags from geometric data blocks.

## Components

### Buttons
- **Primary:** Gradient fill `linear-gradient(135deg, #3B82F6 0%, #2563EB 100%)`, solid text `#FFFFFF`, hairline top highlight `inset 0 1px 0 rgba(255, 255, 255, 0.2)`. Hover state triggers a subtle outer photonic glow (`rgba(59, 130, 246, 0.4)`).
- **Secondary (Glass):** Background `rgba(255, 255, 255, 0.05)`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#E2E8F0`. Hover state shifts background to `rgba(255, 255, 255, 0.1)`.
- **Tertiary / Ghost:** Transparent background, text `#94A3B8`, text hover `#FFFFFF` with hover background `rgba(255, 255, 255, 0.04)`.

### AI Model Cards
- **Structure:** Multi-layered glass plate (`Tier 1` elevation). Top header houses the model logo, model title, creator badge, and category tag.
- **Benchmark Bar:** Inset container (`rgba(0, 0, 0, 0.3)`) displaying contextual metric bars (Context Window, ELO Rating, MMLU score, Latency ms) with animated horizontal fill lines in Electric Blue or Neon Cyan.
- **Hover Action:** Surface shifts to `Tier 2`, glowing boundary illuminates at `rgba(59, 130, 246, 0.3)`.

### Chips & Badges
- **Category Tags:** Pill shape (`9999px`), `font-size: 11px`, `font-weight: 600`, uppercase Latin tracking or clear Persian medium weight. Incorporates a small circular glowing node (`6px` diameter) anchored on the leading edge (right in Persian, left in English).
- **Filter Chips:** Toggable chips with `rgba(255, 255, 255, 0.06)` background. When active, transition to solid `#3B82F6` with an embedded dismissal icon.

### Form Inputs & Search Fields
- **Global Search:** Surface `rgba(15, 23, 42, 0.8)` with backdrop blur `12px`, border `1px solid rgba(255, 255, 255, 0.1)`.
- **Focus State:** Border transitions instantaneously to `#06B6D4`, casting an ambient rim highlight `0 0 0 3px rgba(6, 182, 212, 0.2)`.
- **Adornments:** Keyboard shortcut prompt (`⌘K` / `Ctrl+K`) rendered in low-opacity monospace text on the trailing margin.

### Checkboxes & Radios
- **Control Base:** `18px × 18px` squares (checkbox) or circles (radio), border `1.5px solid rgba(255, 255, 255, 0.2)`, background `rgba(15, 23, 42, 0.5)`.
- **Checked State:** Fill `#3B82F6`, check icon rendered in pure white `#FFFFFF` with micro pop animation.

### Comparison Matrix & Radar View
- **Diff Table:** Alternating rows using `rgba(255, 255, 255, 0.015)` zebra stripes. Sticky column headers locked to glassmorphism `Tier 3`.
- **Winner Delta Highlight:** Cells showcasing the superior specification among compared models receive an Emerald accent border `rgba(16, 185, 129, 0.4)` and a soft green glow background `rgba(16, 185, 129, 0.08)`.
